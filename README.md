# GeneratePress Child Theme - ISPAG 🎨

Thème enfant de GeneratePress : identité visuelle d'ISPAG et **modèles de pages** des outils métiers (CRM, projets, cuves).

## Contenu
- **Modèles de pages** :
  - entreprises et contacts : listes, fiches détaillées (dont version responsive) et profil utilisateur ;
  - offres : kanban, liste et détail ;
  - projets : détail d'un projet avec colonne de droite (entreprise, contacts, pièces jointes) ;
  - tâches : tableau de bord ;
  - cuves : formulaire de cuve et fiche technique publique ;
  - modèles de messages.
- **Éléments d'interface** : barre d'actions, cartes (entreprise, contact, offre), recherche, tableau des offres, export, fenêtres de modification en ligne (popover), création rapide d'entreprise et de contact.
- **Responsive** : mise en page adaptée aux téléphones et tablettes, utilisables en atelier.
- **Droits** : les pages s'ouvrent selon les droits ISPAG (`view_company`, `view_contact`, `real_all_orders`, …) ; les blocs sans droit ne sont pas affichés.
- Mise à jour automatique depuis GitHub ; traductions FR / DE dans `languages/`.

## Installation
Installer GeneratePress, puis ce thème enfant, et l'activer. Les pages utilisent les plugins ISPAG (Project Manager, CRM, Achats, Tank Builder) : les installer et les activer avant d'afficher les modèles.
